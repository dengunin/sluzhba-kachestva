# Служба качества — портал (этап 1)

Статический сайт на GitHub Pages: только просмотр сводки, которую публикует приложение «Генератор протоколов
испытаний» («Ещё» → «Опубликовать на портал» и автопубликация). Вход — по паролю сайта.

- `index.html`, `assets/` — сайт без сборки и фреймворков (HTML + CSS + JS), шрифт IBM Plex Sans (Google Fonts),
  логотип — из приложения.
- `data/portal.enc` — сводка по всем ПР, зашифрованная паролем сайта (AES-256-GCM, ключ — PBKDF2-SHA256). Файл
  пишет только приложение через GitHub API; руками его не править.

В репозитории нет токена, пароля, документов и открытых данных. Без пароля видна только страница входа.

Разделы: Обзор · Распоряжения · План работ · Задачи (этап 2) · Результаты · ОТК (этап 2) · Замечания · Аналитика.
Адреса — через хеш (`#/orders/ПР-26-206/equipment`, `#/remarks?tab=open`): прямая ссылка открывает тот же экран.

Проверка локально: положить тестовый `data/portal.enc` в копию папки вне репозитория и открыть через
`python -m http.server` (расшифровка работает только на https или localhost).
